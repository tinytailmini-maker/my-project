## 실제 업로드 방법

**쇼츠 (바로 사용 가능)**
- `shorts/NNN.mp4` 는 H.264/AAC 1080×1920 완성본 → YouTube Shorts·TikTok·Reels에 바로 업로드.
- 무음 트랙 포함(호환용). 업로드 시 **앱 내 트렌드 음원**을 얹으면 도달이 더 늘어납니다.

**캐러셀 (슬라이드 이미지로 내보내기 필요)**
- `carousels/NNN_*.html` 는 디자인 원본. 각 슬라이드 7장을 **1080×1350 이미지로 캡처**해서 인스타 캐러셀로 업로드.
- 캡션·해시태그는 파일 하단 "投稿キャプション" 박스에 있음(원터치 복사 버튼 포함).

**컴플라이언스**: 전 게시물 일반 지식 기반 · 브랜드 공식 이미지 미사용(오리지널 그래픽) · 판매 유도는 프로필 링크에서만.

■ 먼저 알아야 할 핵심 1가지
------------------------------------------------
인스타에서 "눌러서 이동되는 링크"는 → 오직 "프로필 링크" 하나뿐.
· 캡션에 URL 적어도 → 안 눌림(글자일 뿐, 복사는 됨)
· 댓글에 URL 적어도 → 안 눌림
· 스토리 '링크 스티커' → 눌림(O)
→ 그래서 "링크는 프로필에" 두고, 나머지는 "프로필 링크로 오세요" +
  "BUYMA에서 luxmall1004 검색"으로 안내한다.
  (긴 /r/ 링크는 사람이 못 외우니, 이미지엔 링크 대신 이 안내를 넣음)


■ 이 링크를 "넣을 자리" 전부 (많을수록 좋음)
------------------------------------------------
[클릭 되는 자리 = 여기에 /r/ 링크를 직접 넣기]
[ ] 인스타 프로필 링크         ← 필수. /r/ 링크 붙이기
[ ] 인스타 스토리 링크 스티커   ← 게시물 올릴 때마다! (전환 제일 잘됨)
[ ] 유튜브 쇼츠 '설명란'        ← 클릭 됨. /r/ 링크 붙이기
[ ] 틱톡 프로필 링크           ← 클릭 됨. /r/ 링크 붙이기
[ ] (선택) lit.link 랜딩 만들어 프로필에 넣고 그 안에서 /r/로 연결

[클릭 안 되는 자리 = "안내 문구"로 유도]
[ ] 인스타 고정 댓글: 正規品はプロフィールのリンク／BUYMAで「luxmall1004」検索
[ ] 캡션 하단(이미 캡션에 링크+검색어 넣어둠 → 복사 가능)
[ ] 캐러셀 마지막 장(이미 ①프로필링크 ②luxmall1004검색 넣어둠)


■ 3층 구조 (이렇게 같이 씀)
------------------------------------------------
[1층] 프로필 링크          = /r/ 링크 (뼈대, 필수)
[2층] 스토리 링크 스티커    = 매 게시물마다 (외부 유입 1등)
[3층] 고정댓글+마지막장     = "프로필 링크 / luxmall1004 검색" 안내


■ /r/ 링크 vs 원본 링크
------------------------------------------------
· /r/ 링크(추천·확정): 인스타에서 온 방문/구매를 "측정" 가능 → 이걸 메인으로.
· buyer/...html(원본): 추적 안 됨. 굳이 쓸 이유 없음.

[ ] 게시물 올릴 때마다 → 스토리 재공유 + 링크 스티커(/r/)

[ ] 캡션은 폴더의 caption.txt 그대로 복붙(링크·검색어 포함됨)
